mim 1.0.0 -- Documentation Index

A single-file, immediate-mode GUI library for JavaScript (Dear-ImGui style, zero dependencies, backend-agnostic). This reference is generated from the JSDoc in mim.js and addons/*.js.

Namespaces

Mim&nbsp;
Mim.ColorColor helpers: rgba, hex, mix, withAlpha.
gui.addons.plots2D plots that scale with the window: draggable bezier curves, polar curves, heatmaps, bar charts and multi-series line charts.
gui.addons.t3d3D plots: wireframe surfaces and point clouds.
gui.addons.tablesAn advanced data table: column sorting (null-safe, click the header), row selection, column resize, and an optional row filter.
gui.addons.colorA color picker: swatch button + inline picker with a 2D saturation/value pad, a hue bar, an optional alpha slider, a validating hex field and a preset palette.
gui.addons.notifsToast notifications: a top-right stack with fade in/out, type-colored (info / success / error) and a time-to-live.
gui.addons.widgetsDear-ImGui-style extras: a horizontal grabber (drag bar), an animated spinner, and a bullet (circle + inline text).
gui.addons.markdownLightweight markdown text: **bold**, *italic*, `code` chips and word wrapping.
