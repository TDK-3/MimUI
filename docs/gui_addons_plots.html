Namespace gui.addons.plots

2D plots that scale with the window: draggable bezier curves, polar curves, heatmaps, bar charts and multi-series line charts. All state (drags, colors) is kept in the id-keyed widget state, so duplicate labels in different windows are independent. Shared options for every plot (all optional): - h: explicit height in px (legacy behavior) - share: split the remaining region height evenly with share-1 sibling plots in the same window (tracked per frame) - min / max: force the value range - grid: draw the 5x5 grid (default true) - axisLabels: min/max readout in the corners (default false) - label: draw the caption above the plot (default true) Width always follows the window; with no h/share the plot fills the remaining height. Every function returns the plot box ({ x, y, w, h, inner: { x, y, w, h } }).
