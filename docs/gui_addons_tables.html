Namespace gui.addons.tables

An advanced data table: column sorting (null-safe, click the header), row selection, column resize, and an optional row filter.

Functions

The advanced table.

Parameters:
stringlabel
Arraycols[{ id, label, width?, align? ('left'|'right') }, ...] — the header row comes from these (clicking a header sorts by its id)
Arrayrows[{ id, ...cellValues }, ...] — row.id keys the selection, so it survives re-sorting and filtering
Objectopts (optional)
numberopts.h (optional)explicit height

booleanopts.selectable (optional)rows toggle a selection on click
booleanopts.sortable (optional)headers sort on click (default true)
booleanopts.zebra (optional)striped rows
booleanopts.filter (optional)draw a search line: rows whose cells do not contain the text (case-insensitive) are hidden
Returns
