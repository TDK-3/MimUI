Class GUI

The immediate-mode GUI. One instance per app; it owns the window/widget state, the style, the flags, the renderer proxy and the addons.

A frame is: beginFrame(input) → beginWindow / widgets / endWindow (repeat) → endFrame(). See the README “Quick start” section for a full example.

Constructor

GUI (Object renderer, Object [options], Object [options.style], Object [options.flags], Object [options.clipboard], boolean [options.addons], boolean [options.debugOverlay])

Creates a GUI instance.

Parameters:
Objectrendererthe backend renderer object -- see the &ldquo;Implementing a backend&rdquo; README section and the backend tutorial for the full contract
Objectoptions (optional)construction options (see below)
Objectoptions.style (optional)partial style ({ theme, colors, vars, font })
Objectoptions.flags (optional)behavior flags -- every key of gui.flags is toggleable, at construction time or later at runtime
Objectoptions.clipboard (optional){ read: () => string, write: (text) => void }
booleanoptions.addons (optional)which addons to attach: all registered addons (default), false for none, or a list of names
booleanoptions.debugOverlay (optional)draw the debug overlay in endFrame
