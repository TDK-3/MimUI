Namespace gui.addons.notifs

Toast notifications: a top-right stack with fade in/out, type-colored (info / success / error) and a time-to-live. Queue with toast(), then draw() once per frame from the Foreground layer: gui.layer(Mim.Layers.Foreground, function () { notifs.draw(); })
