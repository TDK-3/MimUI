Namespace gui.addons.color

A color picker: swatch button + inline picker with a 2D saturation/value pad, a hue bar, an optional alpha slider, a validating hex field and a preset palette. Colors are [r, g, b, a] arrays (0..255); a semi- transparent swatch is drawn over a checkerboard.
