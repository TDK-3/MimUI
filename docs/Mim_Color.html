Mim.Color

Color helpers. Colors are plain [r, g, b, a] arrays (0..255). Never mutate a color you obtained from the style; mix/withAlpha return new arrays.

Functions

Mim.Color.rgba(...)Builds an [r, g, b, a] color array (ints, alpha defaults to 255).
Mim.Color.hex(...)Converts a hex string to [r, g, b, a]: '#rgb', '#rrggbb', '#rgba', '#rrggbbaa' (with or without the leading '#').
