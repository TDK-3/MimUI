Class Style

The visual style: named colors (style.colors), numeric metrics (style.vars) and the font (style.font). Construct one with a partial override object, or read it from an existing GUI via gui.style.

Constructor

Style (Object [partial], string [partial.theme], Object [partial.colors], Object [partial.vars], Object [partial.font])

Creates a style from a partial override object.

Parameters:
Objectpartial (optional)override object
stringpartial.theme (optional)'dark' (default) or 'light'
Objectpartial.colors (optional)color name -&gt; [r,g,b,a] | '#hex' | {r,g,b,a}
Objectpartial.vars (optional)var name -&gt; number (or [x, y] for vector vars)
Objectpartial.font (optional){ size, id }
