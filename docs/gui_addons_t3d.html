Namespace gui.addons.t3d

3D plots: wireframe surfaces and point clouds. Drag to rotate, wheel to zoom; the orientation and zoom are kept per label in the widget state. Options: h/share as with the 2D plots, plus spin (rad/sec auto-spin, 0 off) and grid (surface resolution, default 18).
